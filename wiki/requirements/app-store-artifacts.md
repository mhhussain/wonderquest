# App Store Artifacts & Publish Checklist

**Purpose**: Everything needed to ship Wonder Quest v1 to TestFlight / the App Store (Kids Category).
**Status**: spec-only.

## Identity

- **Display name**: Wonder Quest (set in `ios/Runner/Info.plist` → `CFBundleDisplayName`)
- **Bundle id**: currently `com.hussain.wonderQuest` in the Xcode project. Final value is the owner's call at upload time — change in Xcode (Runner target → Signing & Capabilities) before the first App Store Connect upload; it cannot change after.
- **Version / build**: `pubspec.yaml` `version: x.y.z+n` drives `CFBundleShortVersionString` (x.y.z) and `CFBundleVersion` (n). Bump `+n` on every TestFlight upload; bump x.y.z per release.
- **App icon**: generated by `app/tool/gen_icon.dart` (`flutter test tool/gen_icon.dart` from `app/`), applied with `dart run flutter_launcher_icons`.

## Privacy

The app collects **no data**. Everything is stored in a single local JSON save file on the device. No network calls, no analytics, no third-party SDKs, no ads, no purchases.

### App Privacy questionnaire (App Store Connect)

Answer: **"Data Not Collected"** for every category. No tracking. No third-party partners.

## Manual QA script (run on a real iPad, airplane mode)

1. Fresh install; enable airplane mode before first launch.
2. Launch → Expedition Map appears; sound plays.
3. Play **one activity in each of the 7 lands**; each ends in a reward modal; HUD stars/XP increase.
4. Force-quit the app (swipe away).
5. Relaunch → all progress persisted (stars, stickers, progress bars).
6. Tap 👪 → parent gate blocks a wrong answer, accepts the right product.
7. Dashboard reflects the play session (minutes today, letters/numbers, skill bars).
8. Settings → Reset all progress → confirm → everything back to zero.
9. Arabic TTS spike: verify Arabic letter names are spoken correctly on device (see `arabic-tts-spike-result.md` — still needs device verification).

## Upload steps

1. `cd app && flutter build ipa` (requires signing set up in Xcode).
2. Upload via Xcode Organizer or `xcrun altool`/Transporter.
3. TestFlight internal testing → run the QA script above → submit for review with the Kids Category questionnaire.
